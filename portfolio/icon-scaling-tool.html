Icon Scaling Tool

@ Fluent Design Studio, Microsoft
about

A Figma plugin used internally at Microsoft and available world-wide. Scales icons in Figma and exports them in PDF & SVG formats. Built in close collaboration with designers and woven into the bi-weekly icon push that ships updates across Microsoft's product surfaces.

contributions
  1. worked directly with designers to understand their workflow needs and iterated on the plugin accordingly
  2. made the plugin completely headless so it could run as part of the automated bi-weekly icon release pipeline
  3. combined vector paths to reduce SVG node count (squashing), cutting file size and improving render performance
  4. added metadata export for each icon component — covering metaphors, descriptions, sizes, and themes
