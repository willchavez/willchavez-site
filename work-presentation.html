Bebop

@ Microsoft · M365 Copilot · 2025–2026

What does a well-designed AI response actually look like?

context

Microsoft's redesign of M365 Copilot. When we started, AI output was a wall of text — accurate, but visually inert. My work was about response design: making AI output feel like something worth reading.

process
  • Needfinding Where responses fell short, what confused users, where existing patterns created friction
  • Design alternatives Multiple directions for response layout, affordance placement, and the input-to-response transition
  • High-fidelity prototypes Timing, motion, and response rhythm — things static designs can't communicate
  • Leadership reviews Structured feedback loops to pressure-test decisions and drive iteration
decisions
  • Response composition as a system, not a template Hierarchy patterns and affordance placements that flex with content type — any response had to feel designed, even when the structure was unpredictable
  • Affordances that feel ready, not demanding Refiners, suggestions, follow-ups — available without competing with the response itself
  • The input moment as an emotional beat Making "send" feel like the start of a conversation, not the submission of a form
outcome

shipped The work shipped as part of the M365 Copilot redesign featured in Microsoft's "Introducing a new design for Microsoft 365 Copilot" article, May 2026.

GenUI

@ Microsoft · M365 Copilot · 2025–2026

What if the format of AI output was a design decision, not a technical default?

context

If a language model can generate anything, why render its output as markdown? GenUI explored composable, structured UI as an output medium — part of a broader "Expressions" art direction initiative at Microsoft.

process
  • Part of "Expressions" — a Copilot art direction initiative Defining what Copilot output could look and feel like beyond plain text
  • Prototype-driven No established patterns to follow — the prototype was the design artifact
  • AI-integrated output components Wired real model responses into the structured layouts — not dummy content
decisions
  • Layout as a semantic signal Structure communicates the type of response before you read a word
  • When to switch from prose to structure Thresholds based on query complexity, information density, and response length
  • Making the generative feel designed Tight compositional constraints — so output feels crafted, even when assembled dynamically

Agent Builder

@ Microsoft · M365 Copilot · 2024–2025

How do you make AI agent creation feel like something anyone can do?

context

Agent configuration had been a developer task. If agents were going to be first-class in a consumer product, the creation experience had to feel native — not a separate setup wizard users had to context-switch into.

process
  • Embedded with the Agent Builder team Weekly syncs to align on prototyping progress and keep design and engineering in dialogue
  • Three interaction flows explored in parallel Varying entry point, level of guidance, and degree of control — a real basis for comparison
  • Early and iterative design reviews Shared rough direction early to clarify requirements before they compounded
  • Guided user testing — ~15 participants Walkthroughs of all three flows; surfaced where users got stuck and which felt most natural
decisions
  • In-flow creation over wizard UI Creation lives inside the conversation — no context switch, no separate setup screen
  • Progressive complexity without a cliff Low floor for first-timers, high ceiling for power users — no invisible wall between them
  • Making capability legible Lightweight signals so users know what their agent can do — and trust that it will behave as configured
screenshots
on designing for the new

AI experiences fail when they look familiar but behave alien. The right starting point is the model's actual behavior — not the nearest UI pattern that looks close enough.

The design decisions that matter most are about trust and legibility: what does the system owe the user in terms of transparency about what it's doing?
