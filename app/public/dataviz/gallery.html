Core principles

Four cross-cutting rules govern every chart: corner-radius scales with data-point width, role-based Segoe typography with K/M/B abbreviation, three density tiers, and the expression-family palettes paired with accessibility patterns.

1 · Corner radius

Radius follows data-point width (hardcoded px, not theme tokens). Round only the free edge; the axis-meeting edge stays square.

4–10px→210–20→420–30→830–50→1250+→16

2 · Typography roles

All dataviz text uses the functional (Segoe) set. Numbers abbreviate K/M/B (uppercase, no space); commas at 4+ digits.

1.2M Large title — hero / donut center
Monthly revenue Body small — chart title
8,210 Body small strong — callout value
REVENUE Caption strong — axis title
240K Caption — axis tick

3 · Density

Compact / regular / spacious tiers in 4px steps. Bars: 8px min width, 32px default, gap ≥ 1:1 with bar width.

4 · Color + patterns

Qualitative default order (loud weight, alternating heavy/soft hues): blue · yellow · purple · green · pink · lime · navy · pumpkin. Patterns always accompany multi-series for high-contrast / color-blind users.

Qualitative (colour + pattern)
Sequential (blue heavy→subtle) · Diverging (blue↔gray↔red) · Threat (green→yellow→red)

On-mark labels flip light/dark per fill (measured contrast), never one fixed colour across a multi-weight ramp.

Axis — foundational (cartesian)

The X/Y cartesian chrome shared by bar, line, area, scatter and heatmap. Three independent line variants. Y starts at 0, ≥3 ticks (default 6), right-aligned numeric labels, a 1px zero baseline heavier than the grid, no top/right spines. The axis sheds its own hover triggers so exploration lives in the data callout.

Grid lines & the 6×1px tick marks share one stroke token (--gnrc-color-stroke-neutral-subtle); the zero baseline uses the next-heavier --gnrc-color-stroke-neutral-soft. Overflow cascade: drop → rotate 45° → truncate + tooltip.

Legend — foundational (interaction)

A key and a control, always below the chart. Hover / focus a series to spotlight it (transient de-emphasis of the rest); click to filter (sticky, reversible). Swatches carry colour and shape so the encoding survives color-blindness. Arrow keys move between items, Enter/Space toggles, each announces "item N of M".

Interactive legend on a grouped bar chart

Hover a bar or a legend chip → sibling series dim with the one shared de-emphasis treatment. Click a chip to latch a filter (this demo is multi-select).

Multi-select filter (union). Click again to clear. Hover is a transient preview and never commits.

Callout — foundational (interaction)

The shared floating card that surfaces a data point's identity + value. Hover and keyboard focus are equal triggers and show identical content (parity). Every inspectable mark carries an accessible label restating its value, a visible focus ring, and is reachable in tab / arrow order — so the value never hides behind an interaction that isn't there.

Parity demo — try both a mouse and the keyboard

Tab into the bars below, then use ← → to walk them. The same card opens on focus as on hover; siblings recede. A screen-reader label ("{category}. {series}, {value}.") is announced for each.

Accessible-label contract: point on line/area → "{x}. {series}, {value}." · bar → "{category}. {series}, {value}." · cell → "{row}, {column}. {series}, {value}." The visible card and the label are two renderings of the same data — kept in sync.

Bar chart

Value tied to a category, encoded by length. Vertical variants sit on the cartesian axis; horizontal variants are axis-less row stacks. Bars always start at 0. Multi-series get colour + pattern and an interactive legend. Below 8px width → switch to area/line.

Vertical · basic

Single series → one neutral fill, no legend. Rounded top only; square base on the axis.

Vertical · stacked

Composition within each category. Every segment is a rounded pill separated by a 1px gap.

Vertical · grouped

Two cuts side-by-side; X tick marks omitted (bar position anchors the label).

Horizontal · basic ("of total")

Long labels; no axis, no grid. Track conveys budget-of-total; trailing value is the precise label.

Horizontal · mini (inline)

Axis-less glyphs embedded in a table; surrounding context supplies the label.

Area / line chart

Continuous trends. Interaction is built around the horizontal (time) position: a crosshair snaps to the nearest X and one shared per-X callout lists every series at that moment. Pinpoints reveal on interaction, not at rest. X axis is point-anchored and must be labelled.

Move the pointer across the plot (or tab in and use ←/→): a vertical guide line snaps to the nearest position and the shared card compares all series at that moment.

Scatter / bubble — provisional visuals

Two continuous measures as discrete points — correlation, clusters, outliers. Bubble encodes a third dimension by marker area; multi-series encode a category by colour and shape (never colour alone). Per-point inspect callout; markers grow when active, siblings dim.

Multi-series bubble scatter

Each series = a distinct expression family + a distinct marker shape. Bubble radius = deal size. Legend swatch mirrors the shape.

Sparkline

A 24×126px trend glyph — silhouette first, no axes. For high-cardinality tables and KPI tiles. Trend arrow + value are redundant text cues; a dense table exposes trend + value through the row, not one focus stop per glyph.

Per-host CPU trend (table)

Colour the line or the value, not both. Values right-aligned so digits line up. Each row carries a text alternative.

Donut chart

Proportion / part-of-whole where change-over-time doesn't matter. Center value = the whole (stays put on hover). Slices descend clockwise from 12 o'clock; sub-2% slices roll into "Others" (its card lists the nested breakdown). Per-slice labels sit outside the ring on the neutral surface to keep contrast. Legend below, interactive.

Revenue by product line

Each slice is a focusable data point — hover / focus singles it out and opens its card while the rest dim. 2px accessibility-stroke allowance preserved.

Gauge chart

A value against a fixed min/max scale. Exactly 180°; the needle stops at the value with no overshoot. Sizes unlock chrome progressively: Small = arc + number; Medium adds min/max; Large adds threat-diverging threshold zones + needle + status label — and must be paired with an action.

KPI tile

A label + hero number. Trend is carried by an icon (never by colouring the number). Static tile — interaction belongs to the parent card. Numbers abbreviate K/M/B. Fixed 170px width; abbreviate rather than resize.

Count Annotation Bar

Compact category overview that doubles as a list filter. A 4px colour bar anchors the category; title + count. Clickable CABs toggle Filled ↔ Outline; multi-select is additive (OR). State is announced, not colour-only.

Heatmap

Two dimensions × magnitude → colour, on the axis "No lines" variant. 1px structural cell gap, 60×28px cell floor (bin, don't shrink). In-cell value labels flip light/dark by a measured contrast test against each cell's own fill. Cells form a 2D grid for arrow-key navigation.

Requests per hour × weekday (sequential)

Sequential blue ramp (heavy = high). Hover / focus a cell to inspect; the rest dim. Missing data renders as a diagonal hatch (a third state), never white.

Gradient colorbar: low → high.

Sankey chart

Flow between column groups; stream width = value transferred. Streams tinted by source category (trace one colour through); boxes stay neutral. Hover / focus a node or stream highlights its connected path and dims the rest. Stream callout carries the target, value, and a part-to-whole share.

Traffic source → landing → outcome

Hover / focus a stream to light its source→target chain. Conservation of flow: each column's totals balance.

Funnel chart — provisional visuals

Sequential stages that monotonically narrow — conversion / drop-off. Band width = value relative to the first stage; the narrowing is the drop-off. Always surface the conversion ratio, not just the raw value. Stage labels live in a clear lane, never on a band.

Basic funnel

One value per stage; neutral fill; no legend. Callout shows value + % of first stage.

Stacked funnel (by region)

Same categories run through every stage, each holding its colour + pattern.

Tree chart

Hierarchy / org chart — structural, not quantitative. Parent → branches → children. Nodes never overlap; branch lines never cross node boxes. Parent title (14px) is larger than child title (12px).

Org structure

Text-only hierarchy; no metrics required. Outlined nodes with 1px heavy stroke.
