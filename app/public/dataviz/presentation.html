Section 1

Dataviz is a skill, not a folder of components

Instead of one giant spec, the guidance is split into small, composable pieces. Each chart inherits from shared layers rather than re-describing everything. Read from the top down:

Layer 1

Core principles

Four cross-cutting rules — radius, type, density, color — that apply to every chart.

Layer 2

Primitives

Shared building blocks — the axis, the legend, the callout — reused across chart families.

Layer 3

Chart types

Bar, line, donut, gauge… each only describes what's unique to it and defers the rest.

Layer 4

Build skills

Technology translations — e.g. turning a chart spec into a real Figma drawing.

The rule that makes it work: when a chart is silent on something, it defers to the layer above it. A bar never re-defines corner radius — it inherits it. That keeps the whole system consistent and lets one change ripple everywhere.

Section 2 · Layer 1

The four core principles

Every chart inherits these before it draws a single mark.

01 · Corner radius

Rounding scales with width

Wider marks get a larger radius (a 32 px bar → 12 px radius). Round the top of a bar, never the edge that meets the axis — values feel objectified, not glued down.

02 · Typography

Role-based text styles

One type role per element — axis titles are Caption-strong, ticks are Caption, hero numbers are Large title. Big numbers abbreviate as K / M / B and use commas past four digits.

03 · Density

Three padding tiers

Spacing steps in 4 px increments off compact / regular / spacious intents. Bars: 8 px minimum width, 32 px default, gaps at least 1:1 with the bar.

04 · Color + patterns

Palettes carry meaning

Color comes from the fixed expression families — reserved for data, never status. Qualitative for categories, sequential for one metric, diverging for a spectrum. Patterns are the accessible fallback for color-blind & high-contrast.

Section 3 · Layer 2

Interaction primitives

Three shared parts do the heavy lifting for almost every chart. A chart skill just says "I have one of these" — the behavior lives here, once.

Axis

Comprehension

X/Y system with three line variants. Always starts at 0, min 3 markers, and reflows gracefully — drop → rotate → truncate — as space shrinks.

Callout

Exploration

The floating card that reveals one value on demand. Hover and keyboard focus are equal triggers and must show identical content — try tabbing into any chart below.

Legend

Key + control

Maps color to series and filters. Hover to spotlight a series; click to filter it out. Sits below the chart, collapses to “+N” when tight.

Section 4 · Layer 3

The chart library

Each chart type below shows a few live examples with real Fluent expression colors. Every mark is keyboard-focusable and opens the shared callout; multi-series charts have interactive legends.

Overlays a distinct texture per series on top of color — the accessible fallback for color-blind & high-contrast viewers, keyed into the legend too. Applies only where color encodes a category or series (not KPI, sparkline, single-series, or gradient heatmaps).

Section 5

AI → Figma: drawing charts automatically

The newest work teaches an AI assistant to draw these charts directly in Figma from the same skills you just saw — no manual pushing of rectangles.

The idea, simply

The dataviz skills describe what a chart is. A new companion skill — dataviz-build — describes how to render that in Figma: where the card goes, how to leave breathing room, how to draw a line, an arc, a flow ribbon.

Ask for “5 gauge charts with random data,” and the assistant reads the gauge spec, reads the drawing recipe, and produces a real, on-brand Figma frame you can inspect and tweak.

Why keep them separate? The chart specs stay technology-agnostic — they don't know about Figma, or React, or anything. Only the build skill knows Figma. Swap in a different tool later and the chart knowledge is untouched.

What the testing loop taught us

Most of the progress is learning captured as durable guidance. A few examples that were found, fixed, and written down so they stay fixed:

Area charts

See-through fills

The area under a line must be translucent, and the line should span the full width — edge to edge.

Gauge

Marker orientation

A small triangle riding the band's inner edge, apex pointing outward toward the rim — a fixed orientation that never flips.

Sankey

Seamless ribbons

Smooth, borderless flow streams — colored by source, distinct from the node boxes, no stray corners.
